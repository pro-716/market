# سوق عصري — واجهة مطوّرة 3D

تمت ترقية المشروع إلى واجهة ثلاثية الأبعاد تفاعلية في الفرع الرئيسي (main):

التغييرات الأساسية:
- دمج واجهة modernize-ui وتطويرها لتشمل تأثيرات ثلاثية الأبعاد.
- استخدام Vanilla-Tilt لكروت المنتجات (ميل 3D).
- خلفية ثلاثية الأبعاد في قسم الهيرو باستخدام Three.js.
- معاينة ثلاثية الأبعاد بسيطة داخل مودال المنتج باستخدام Three.js (نموذج مكعب مغطى بصورة المنتج).
- أنيميشن "طيران" للمنتج إلى السلة باستخدام GSAP.
- تغيير صيغة عرض الأسعار إلى الدينار العراقي (IQD) باستخدام Intl.NumberFormat('ar-IQ', {currency:'IQD'}).

معاينة محلية:
- شغّل خادم ملفات محلي داخل المجلد المشروع ثم افتح http://localhost:8000

ملاحظات:
- هذا حل واجهة frontend ثابت (Static). لتحسينات مثل تحميل موديلات 3D حقيقية أو حفظ الطلبات تحتاج إضافة باكند أو CDN لنماذج GLB.
- الأداء: حاول تقليل عدد المجسمات أو تعطيل الخلفية 3D على الأجهزة الضعيفة إن لزم.

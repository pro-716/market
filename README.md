# سوق عصري — واجهة مطوّرة

هذه نسخة مطوّرة لواجهة متجر ثابتة (Static) بلغة عربية، بتصميم عصري ونفحات نيون.

ما الذي قمتُ به في الفرع `modernize-ui`:

- إضافة صفحة رئيسية `index.html` بتصميم حديث، RTL (عربي).
- استخدام Tailwind CSS عبر CDN لتسريع التطوير، مع ألوان نيون وتأثيرات glow.
- أدمجت Alpine.js للمنطق التفاعلي (بحث، فلترة، سلة محلية، مودال عرض سريع).
- أضفت Swiper لعرض شرائح الصور وAOS للانيميشن عند التمرير.
- ملف بيانات `data/products.json` يحوي منتجات تجريبية.
- كود JS (assets/js/app.js) لإدارة المنتجات والسلة باستخدام `localStorage`.

كيفية المعاينة محليًا:

1. افتح الملفات مباشرة: افتح `index.html` في المتصفح (كافٍ لمعاينة وظائف JS/CDN).
2. أو استعمل خادم ملفات محلي بسيط:
   - باستخدام Python: `python -m http.server 8000` ثم افتح `http://localhost:8000`

ما يمكنك طلبه لاحقًا:
- تحويل المشروع إلى React + Vite مع نفس التصميم.
- ربطه بباكند (Firebase / Supabase) لحفظ الطلبات والمستخدمين.
- إضافة صفحات مدفوعات باستخدام Stripe.
- تحسينات SEO وإعداد GitHub Pages.

إذا رغبت، أفتح PR تلقائيًا من الفرع `modernize-ui` أو أدفع تغييرات إضافية (مثلاً إضافة صور فعلية أو شعارك).
